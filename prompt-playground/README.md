# 🧠 Prompt Playground

A simple Generative AI CLI application built using Python and OpenAI API.

This project lets users interact with AI using different prompt engineering modes:
- Chat
- Summarization
- Explanation
- Rewriting
- Creative generation

# ⚙️ HOW TO SETUP & RUN

## 1. Install Python
Check if Python is installed:
python --version  
OR  
py --version  

Download if missing:
https://www.python.org/downloads/

IMPORTANT: Enable "Add Python to PATH"

---

## 2. Clone repository
git clone https://github.com/your-username/genai-builder-portfolio.git  
cd genai-builder-portfolio/prompt-playground  

---

## 3. Create virtual environment
python -m venv venv  

---

## 4. Activate virtual environment
Windows:
venv\Scripts\activate  

Mac/Linux:
source venv/bin/activate  

---

## 5. Install dependencies
pip install -r requirements.txt  

If not working:
python -m pip install -r requirements.txt  

---

## 6. Create .env file
Create a file named:
.env  

Add inside it:
OPENAI_API_KEY=your_api_key_here  

IMPORTANT: Do NOT use quotes

---

## 7. Run project
python app.py  
OR  
py app.py  

---

# 🧠 HOW IT WORKS

1. User selects a mode  
2. User enters input  
3. Input is converted into prompt  
4. Sent to OpenAI API  
5. Response is shown in terminal
